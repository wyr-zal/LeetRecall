# LeetRecall 架构说明

## 产品边界

LeetRecall 是个人 Hot100 复习工具。核心页面仅有快速复习与默写模式；题目导入和设置是轻量辅助页，不包含仪表盘、社区、排名、会员或 AI 对话。

## 数据流

- MySQL 保存题目、复习进度、复习记录、默写模板和默写记录；外部 JSON 草稿只保存校验内容，不保存来源、模型或提示词。
- Spring Boot 提供 `/api` 接口，保存复习记录与更新进度处于同一事务。
- Vue/Pinia 管理当前会话；`localStorage` 只保存未提交草稿和当前题目。
- 默写详情不返回答案；查看答案接口以会话 ID 留痕，提交时由服务端执行 60 分上限。

## 复习调度

- 不会：1 天后。
- 模糊：3 天后。
- 会：首次 3 天，后续间隔翻倍，最多 30 天。

## 部署拓扑

`nginx:80 -> web:80`，`nginx:/api -> server:8080`，`server -> mysql:3306`。MySQL 使用命名卷持久化，Flyway 负责迁移。
